## Publish on GitHub Pages

1. Create a new public repository on GitHub, for example `vimal-karthik-qa-portfolio`.
2. Upload the **contents** of this folder to the repository root (so `index.html` is at the root).
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish. The URL is usually `https://YOUR-GITHUB-USERNAME.github.io/vimal-karthik-qa-portfolio/`.
6. Replace `YOUR-GITHUB-USERNAME` with your actual username; do not put a guessed URL on your resume.

## Before publishing

- Review the phone number and email displayed on the website. They are taken from the supplied resume and will be public.
- Add your actual GitHub and LinkedIn URLs when available. They are intentionally not fabricated here.
- Confirm that your resume is safe to publish publicly. Consider using a portfolio-specific resume with personal details you are comfortable sharing.
- Verify all experience descriptions and keep only claims you can discuss in an interview.
- The sample projects are **demonstration artifacts**, not claims that these exact repositories were used at your employer. Replace or extend them with original work you can share publicly.
- Do not upload employer code, internal URLs, customer data, prompts, test data, screenshots, or confidential implementation details.
